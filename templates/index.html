📋 Help & Guide

🚀 Quick Start

Welcome to the Network Diagnostic Chatbot! Here's how to use it:

📊 Dashboard Features:

  • Status - Current connection status
  • Download - Download speed in Mbps
  • Upload - Upload speed in Mbps
  • Ping - Network latency in milliseconds
  • IP Address - Your current IP address

💬 Chat Features:

  • Type your network issue or question
  • Use 🎤 button for voice input
  • Press Enter or click ➤ to send
  • Powered by AI (Gemini API)

📈 Network Chart:

Real-time visualization of your download and upload speeds.

🌙 Theme Toggle:

Click the moon/sun button to switch between dark and light modes.

📊 Export Report:

Click the chart icon to generate and download a PDF report of your network status.

⚙️ Setup Instructions:

  1. Install dependencies: pip install -r requirements.txt
  2. Create .env file with your API keys
  3. Run: python app.py
  4. Open browser to http://localhost:5000

🔧 Common Issues & Solutions:

  • WiFi not connecting? - Check password, restart router, disable airplane mode
  • Slow internet? - Disconnect unused devices, check signal strength, restart router
  • High ping? - Network congestion or distant servers, try different server
  • DNS issues? - Change DNS to 8.8.8.8 or 1.1.1.1
  • No internet? - Check cables, restart modem, verify ISP connection

💡 Pro Tips:

  • Monitor your network regularly to identify patterns
  • Position router in central location for better coverage
  • Use 5GHz WiFi for faster speeds (shorter range)
  • Close background apps consuming bandwidth
  • Keep router firmware updated
